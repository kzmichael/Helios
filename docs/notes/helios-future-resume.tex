\theme{Delivery and infrastructure}
\begin{itemize}
  \item Replaced manual deploys with GitOps: Argo CD app-of-apps and ApplicationSets reconcile \textbf{100\%} of cluster state from Git; drift is detected and self-healed. % TARGET
  \item Cut merge-to-production lead time to \textbf{under 10 minutes} through GitHub Actions with OIDC federation; deployment success rate held above the \textbf{95\%} SLO without rollback. % TARGET
  \item Eliminated \textbf{every} long-lived cloud and CI credential (OIDC for CI, workload identity for pods, Vault dynamic Postgres credentials), verified through provider audit logs. % TARGET
  \item Shipped canary releases with Argo Rollouts that \textbf{auto-rolled back} a deliberately bad release on an error-rate metric, with no manual action. % TARGET
  \item Defined the same environment in Terraform, Bicep and Pulumi with explicit ownership boundaries (no resource co-owned by two tools); rebuilt the full AWS lab from code and tore it down on a nightly schedule. % TARGET
  \item Built distroless, non-root container images (Go services \textbf{29--40\,MB}) with documented base-image strategy and a scripted image-standard verifier. % FACT
\end{itemize}

\theme{Reliability and observability}
\begin{itemize}
  \item Defined and published \textbf{five SLOs as code} on user-journey SLIs: API read availability 99.9\%, read p99 $<$300\,ms, ingest success 99.95\%, alert delivery p95 $<$30\,s, and \textbf{device-to-map position freshness p99 $<$5\,s} across four services. % TARGET
  \item Instrumented all services with OpenTelemetry (W3C trace context across HTTP, gRPC \emph{and} Kafka) so one trace spans device $\rightarrow$ ingest $\rightarrow$ Kafka $\rightarrow$ API $\rightarrow$ map; exported to \textbf{two} backends to prove vendor portability. % TARGET
  \item Wrote multi-window, multi-burn-rate alerts and error-budget policy; every page links to a runbook with a clear action; removed non-actionable alerts rather than silencing them. % TARGET
  \item Carried the pager through a seeded high-cardinality incident: stopped ingestion before resource exhaustion, cut active series by \textbf{$\sim$90\%}, added a guard, and published a blameless postmortem. % TARGET
  \item Load-tested to \textbf{100k simulated devices} (1\,Hz) and produced a capacity statement covering devices, node count, throughput, p99 latency and monthly cost; scaled consumers on \textbf{Kafka lag} (KEDA) rather than CPU. % TARGET
  \item Ran \textbf{5 chaos experiments and a region-loss game day}; measured \textbf{RTO under 30 min, RPO under 1 min} for Azure failover and failback, and restored Postgres and the cluster into fresh targets with timed drills. % TARGET
  \item Found, reproduced and fixed multiple production-style defects in the application under load, each with a reproduction, root cause, fix, regression test and postmortem. % TARGET
\end{itemize}

\theme{Security and supply chain}
